# Contributing to the QuantumYield concept

Read the [current scope and local setup](README.md) before proposing a change.
Check this repository's
[issues](https://github.com/nykeybanks/patent_2026.10.26_concept/issues) and
[pull requests](https://github.com/nykeybanks/patent_2026.10.26_concept/pulls)
for related work. Report ordinary bugs with reproduction steps, browser details
and expected behavior. Follow [SECURITY.md](SECURITY.md) for sensitive reports.

Keep patches focused and describe what changed, how it was checked and any
unresolved dependencies. Preserve the Win11React attribution, repository license
and third-party notices. Distinguish implemented behavior from proposed
QuantumYield capabilities; use verified official assets for branded artwork.

Work on a branch or fork. The inherited PR preview and CLA workflows still target
upstream accounts and documents. Maintainers need to review that configuration
before opening PRs; a branch comparison or patch can be reviewed without invoking
those workflows. This repository does not establish a new QuantumYield CLA.
