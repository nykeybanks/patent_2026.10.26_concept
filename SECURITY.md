# Security reporting for the QuantumYield concept

This is a development concept derived from Win11React. It does not establish a
production security model or a supported release policy. Some inherited features
still connect to upstream services; see the [dependency record](docs/concept-identity-patch.md).

For ordinary bugs, use
[this repository's issues](https://github.com/nykeybanks/patent_2026.10.26_concept/issues).
Do not include credentials, personal data or sensitive vulnerability details in a
public issue. If GitHub private vulnerability reporting is enabled for this
repository, use that channel. Otherwise, request a private reporting channel from
the repository maintainer without posting the sensitive details. No dedicated
QuantumYield security email or response-time commitment is established here.

The upstream Win11React issue tracker, email addresses and Discord servers are
not QuantumYield support channels.
